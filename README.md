# GroomLux - Premium Men's Salon 3D Landing Page

A modern, interactive 3D landing page for a premium men's salon featuring Three.js animations and a sleek dark theme with gold accents.

## Features

✨ **3D Graphics**
- Interactive 3D barber chair with rotating animation
- Floating 3D scissors
- Animated particle system with physics simulation
- Dynamic lighting and shadows

🎨 **Modern Design**
- Luxury dark theme with gold accents
- Responsive layout for all devices
- Smooth scroll animations
- Professional gradient backgrounds

📱 **Responsive**
- Mobile-friendly design
- Touch-optimized navigation
- Adaptive layouts for all screen sizes

🎯 **Sections**
- **Hero Section**: Captivating introduction with CTA
- **Services**: Grid of salon services with hover effects
- **About**: Company statistics and description
- **Contact**: Contact form and business information
- **Navigation**: Fixed navbar with smooth scrolling

## Tech Stack

- **HTML5** - Semantic markup
- **CSS3** - Modern styling with animations
- **JavaScript** - Vanilla JS for interactions
- **Three.js** - 3D graphics and animations

## Setup

1. Clone the repository
2. Open `index.html` in your browser
3. That's it! No build process required.

## Customization

### Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #1a1a1a;      /* Dark background */
    --secondary-color: #d4af37;    /* Gold accent */
    --accent-color: #2d2d2d;       /* Card background */
    --text-color: #ffffff;         /* Text color */
    --light-text: #b0b0b0;         /* Secondary text */
}
```

### Business Information
Edit in `index.html`:
- Logo name: `<h1>GroomLux</h1>`
- Services: Update service cards in the services section
- Contact info: Update address, phone, and hours
- Social links: Add your social media links in the navbar
